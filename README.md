# 양력·음력 월간 달력

프로그램을 실행하면 **컴퓨터의 현재 날짜를 기준으로 이번 달 달력**이 창으로 열립니다.
각 날짜의 아래쪽에 작은 글씨로 한국 음력 날짜가 표시됩니다. 이전 달/다음 달 이동도 가능합니다.

## Windows에서 실행

Python 3.9 이상을 설치한 다음, 이 폴더에서 터미널을 열고 실행합니다.

```powershell
py -m pip install -r requirements.txt
py lunar_calendar.py
```

- 음력 변환: `korean-lunar-calendar` 라이브러리 사용
- 화면: 파이썬 기본 GUI인 Tkinter 사용
- 한국 음력 라이브러리의 지원 범위(대략 1000~2050년) 밖은 변환하지 않습니다.
- 이 프로그램은 컴퓨터에서 창을 띄우는 데스크톱 프로그램입니다. GitHub 웹페이지에서 코드가 자동 실행되는 것은 아닙니다.
